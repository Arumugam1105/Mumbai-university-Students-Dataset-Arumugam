# Mumbai university Students Dataset Project Overview

The Mumbai University KT Students Dashboard is a data analysis and visualization project designed to analyze the academic performance, lifestyle, demographics, and behavioral patterns of engineering students.

The project focuses on understanding factors related to KT (Keep Term/backlog) status, academic performance, commuting patterns, part-time employment, extracurricular activities, and student well-being.

The dashboard transforms raw student data into interactive visualizations and meaningful insights using Microsoft Excel and Power BI
